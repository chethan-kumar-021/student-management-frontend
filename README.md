# Student Management Frontend

Frontend UI for Student Management System built using HTML, CSS, and JavaScript.

---

## Features

- Add Student
- Display Students
- Delete Student
- Form Validation
- Responsive UI

---

## Tech Stack

- HTML
- CSS
- JavaScript

---

## Project Structure

```text
frontend/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

---

## Run Project

Open:

```text
index.html
```

using Live Server.

---

## Backend API

Connected with Flask Backend API:

```text
http://127.0.0.1:5000
```
